# Git Soutenance - Projet Voiture

## Description
Ce dépôt a été réalisé dans le cadre d'une soutenance Git.
Le projet repose sur un thème simple : les composants d'une voiture.

## Objectif
L'objectif principal est de démontrer la maîtrise de Git et GitHub :
- gestion des branches
- gestion des issues
- pull requests
- templates
- hooks
- intégration continue
- organisation du dépôt

## Structure du projet
- `index.html` : page principale
- `css/style.css` : feuille de style
- `docs/` : documentation textuelle sur différents composants d'une voiture
- `plans/`, `brouillons/`, `exports/` : éléments non versionnés via `.gitignore`
