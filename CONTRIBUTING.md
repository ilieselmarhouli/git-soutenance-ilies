# Guide de contribution

## Règles de contribution
- Créer une issue avant toute modification importante
- Créer une branche dédiée par fonctionnalité ou correction
- Utiliser des messages de commit clairs
- Ouvrir une Pull Request pour proposer les changements
- Respecter le git flow défini dans le dépôt

## Convention de branches
- `main` : branche stable
- `develop` : branche de développement
- `feature/...` : nouvelles fonctionnalités
- `fix/...` : corrections
- `docs/...` : documentation
- `chore/...` : maintenance

## Convention de commits
Exemples :
- `feat: ajouter une section moteur`
- `fix: corriger le style du titre`
- `docs: ajouter la description du volant`
- `chore: initialiser la structure du projet`
